# FoodBridge – Food Donation & Redistribution Management System

A university DBMS project connecting food Donors, NGOs/Charities, and an Admin
through a simple PHP + MySQL web application.

## Tech Stack
- Frontend: HTML, CSS, Bootstrap 5, JavaScript
- Backend: PHP (procedural, no framework)
- Database: MySQL
- Server: XAMPP (Apache + MySQL)

## Folder Structure
See project root for /admin, /donor, /ngo, /config, /includes, /css, /js, /images.

## Status
Architecture scaffold only. Business logic to be implemented module by module.
